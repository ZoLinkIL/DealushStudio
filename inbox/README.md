# inbox

קבצים שנשמרים כאן עולים ללוח של הסטודיו כפריט חדש בסטטוס "מוכן", ונמחקים מכאן אוטומטית.

```json
{
  "title": "מלון בוטיק באתונה",
  "platform": "ig_post",
  "date": "2026-11-02",
  "time": "19:00",
  "kind": "המלצת מלון",
  "caption": "...",
  "hashtags": "#דילוש #אתונה",
  "affiliate_link": "",
  "images": ["athens-post.png", "athens-story.png"]
}
```

פלטפורמות: `ig_post`, `ig_story`, `tiktok`, `channel`, `zolink_story`.
התמונות יושבות באותה תיקייה, עד 4MB לתמונה.
